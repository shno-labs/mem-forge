# Original-Artifact image delivery experiment

Status: bounded transport prototype; not extraction or release acceptance.

The original revision-pinned Artifact remains the only Evidence. Ordered whole
and overlapping detail views deliver its pixels to the structured client; they
have no independent Evidence identities. Source-format interpretation stays in
source adapters. Raster geometry knows only pixel/patch bounds, while the LLM
delivery boundary owns the documented experimental model profile, request
accounting and labels. Callers retain current source/access/authority stale guards.

The optional typed delivery bundle carries the original hash, catalog/ref,
Observation/revision, source/revision, access/authority assertion, model/budget,
renderer and wire/pixel identities. Validation derives expected views again.
Native, fallback, schema correction and retry requests use the same bundle;
each actual expanded prompt is capacity-checked. Existing tuple-based callers
retain the existing image preparation path. No production extraction caller
enables the new bundle in this change.

Offline validation retained 89 selected passing checks after the final change,
and the earlier structured-client/batch-runner selection passed 124 checks.
Independent finite controls checked complete pixel coverage, rehashed wire
tampering, missing detail views, unknown Artifact binding, context relabeling
limitations and transport dependency selection. Three focused public-boundary
tests verified stable retry/fallback inputs, correction-growth rejection and
false-valued injected callables. Lint and diff checks passed. The six final
implementation/test files match the independent review and actual online freeze.

The real pinned [revision-update diagram](../design/images/revision-update-flow.png)
is 2040 by 2410 pixels, SHA256
`1bddb850aeb0d2b51cf78a3a4c7649b2c422718bb51a504ea6e0f35ef16234aa`.
Its delivered whole view and six lossless overlapping detail views cover the
complete original pixel plane. The manifest SHA256 is
`f8de75c3d6a111bff20af4d5ef24ecf741c315dd3f62b783246f704ab363a4fa`.
Actual requests used the CF dev app's model binding and online
`sap/anthropic--claude-4.6-sonnet`, requesting 32,768 output tokens. Provider
requests completed, but independent source-only reviews still found wrong
branch routing and missing target-design qualification. The later complete
formation/audit operation produced 24 private candidates and failed semantic
acceptance. Delivery fidelity does not prove diagram understanding.

This experimental profile supports one upright single-frame PNG. Documented
standard-tier image bounds and estimated wire size are not managed-route
capacity attestations. A self-consistent rehashed context relabel can validate
as a bundle: only the caller can authenticate its current access/authority.
Production integration, additional input profiles, caller authority, adapter
parity, full extraction acceptance and CF deployment/smoke remain open.

The versioned second profile places all reading views before the query, following
official vision/long-context prompting guidance. Its source/ref binding and all
seven image bodies/rectangles remain unchanged; ordering participates in the
delivery identity. Current image/client tests passed 17 checks, with lint/diff
clean. A separate complete online four-source operation retained 106 candidates
after eight native Sonnet calls; source-only semantic review is separate.

Configured-model image-input capability checking is explicitly deferred by the
user to [issue 497](https://github.com/shno-labs/mem-forge/issues/497), outside
this version. Artifact eligibility and format/token checks do not certify that
arbitrary configured models support images. The current experiment uses the
verified Sonnet route and keeps citation identity independent of image inference.

Both fresh source-only reviewers have now completed all 106 assessments. All
Primary views pass authenticity/readability/directness; nevertheless both find
persistent conflict misrouted to execution error and an ADD condition lost in
raster claims. All original hashes remain unchanged. This cohort fails semantic
acceptance despite clean model audits; ordering/delivery is not a guarantee of
understanding.

Canonical design and full retained development evidence are in
[the proposed extraction design PR](https://github.com/shno-labs/mem-forge/pull/495).
Private source/response bytes, credentials and personal identifiers are excluded
from this repository. This change does not authorize partial publication,
caption/OCR replacement of Evidence or reprocessing stored Memories.
